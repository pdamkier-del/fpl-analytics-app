# Deduplicated historical research matrix

Dated 22 November 2026. **54 coverage families are not 54 independent experiments.** Directory/substudy membership is exhaustive for the pinned public result trees in `directory-matrix.csv`; arm-specific source facts, baseline, configuration, periods, population, metrics, decisions and missingness are in `historical-matrix.json.gz`. All original protocols/results remain intact in `primary-evidence.json.gz` and the cited Git objects. Source-only or queued work is not called completed.

Classification is narrow: accepted = original scoped research/checkpoint decision, rejected = that exact tested configuration, exploratory = reused/diagnostic, inconclusive = incomplete/unrecovered evidence, blocked = missing prerequisites, untested = not a generalizable science result. An accepted gate never implies independent predictive validation or deployment. Existing registry states are preserved.

## Copies, variants and unknowns

Identical `(path, Git blob)` versions are collapsed across branches; different blobs at one path remain separate versions. Different arms/seeds/parameter values and calibrated follow-ups remain attached to their original family and directory. A changed file or repeated season is not a fresh hypothesis or untouched holdout. The 225 primary result/protocol artifacts keep every original field, including negative decisions. The 184 directory rows do not count private-manager payloads as performance trials.

The original PR41 inventory has **178 directory groups / 2,471 files**; the expanded branch union has **184 result directories** plus flat result files. `verification.json` checks all 2,471 content hashes and all 236 original test-source paths. Tests are indexed, not re-executed model certification. The public tree index covers 58 branch names at 48 unique commit heads, 3,169 distinct path/blob versions; private-manager branch names and payloads are excluded.

Cases without a machine-readable standard summary are explicitly marked in `directory-matrix.csv`. Detailed missing fields remain NOT_AVAILABLE rather than guessed. The team-xG Actions job succeeded, but its result/log bodies could not be downloaded (Forbidden); numerical claims remain unverified. See LEGACY-051 and its run/digest receipt.

Independent scientific review of grouping and novelty is **pending**; deterministic checks do not replace it.
